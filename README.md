# Exercícios de Python — UNINTER

Este repositório reúne exercícios práticos desenvolvidos durante meus estudos na graduação em Ciência da Computação, na UNINTER.

## Objetivo

Registrar minha evolução no aprendizado de lógica de programação e algoritmos utilizando Python, documentando os problemas propostos, as soluções desenvolvidas e os conceitos praticados.

## Conteúdos abordados

- Estruturas condicionais
- Estruturas de repetição
- Variáveis e operadores
- Funções e modularização
- Listas e dicionários
- Matrizes
- Tratamento de exceções
- Biblioteca Random

## Organização

- `enunciados/`: propostas originais dos exercícios.
- `notebooks/`: códigos e resoluções desenvolvidos em Python.
- `material-original.pdf`: material de referência da disciplina.

## Tecnologias

- Python
- Google Colab
- GitHub
