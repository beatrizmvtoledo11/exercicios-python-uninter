# Exercícios de Python — UNINTER

Este repositório reúne exercícios práticos desenvolvidos durante meus estudos na graduação em Ciência da Computação, na UNINTER.

## Objetivo

Registrar minha evolução no aprendizado de lógica de programação e algoritmos utilizando Python, documentando os problemas propostos, as soluções desenvolvidas e os conceitos praticados.

## Exercício 1 — Sistema de vendas e descontos

Desenvolvimento de um programa para calcular descontos progressivos em compras realizadas em uma empresa de vendas por atacado, considerando diferentes faixas de valor.

- Conceitos praticados:

Variáveis e operadores aritméticos;

Entrada e saída de dados;

Estruturas condicionais (if, elif e else);

Operadores relacionais e lógicos.

## Exercício 2 — Sistema de pedidos de Açaí e Cupuaçu

Desenvolvimento de uma interface de pedidos para uma loja de Açaí e Cupuaçu, considerando diferentes sabores, tamanhos e valores. O programa permite realizar vários pedidos e calcular o total acumulado.

- Conceitos praticados:

Estruturas condicionais aninhadas;

Estruturas de repetição (while);

Validação de entradas;

Acumuladores;

Uso de break e continue.

## Exercício 3 — Sistema de cobrança de uma copiadora

Desenvolvimento de um programa para calcular o valor de serviços de uma copiadora, considerando o tipo de serviço, a quantidade de páginas, os descontos aplicáveis e os serviços adicionais.

- Conceitos praticados:

Criação e utilização de funções;

Parâmetros e retorno de valores (return);

Estruturas condicionais;

Validação de dados;

Tratamento de exceções (try e except).

## Exercício 4 — Sistema de gerenciamento de livros

Desenvolvimento de um sistema para gerenciamento de livros, com funcionalidades para cadastrar, consultar e remover registros por meio de um menu interativo.

- Conceitos praticados:

Listas e dicionários;

Listas de dicionários;

Funções e modularização;

Estruturas de repetição e condicionais;

Manipulação e consulta de dados.

## Exercício 5 — Sistema de Bingo

Desenvolvimento de um sistema de Bingo com geração de cartelas, sorteio de números e identificação de cartelas vencedoras, seguindo as regras estabelecidas no enunciado.

O exercício possui restrições específicas: não utilizar dicionários nem bibliotecas auxiliares além da biblioteca Random, utilizando randint para gerar os números aleatórios.

- Conceitos praticados:

Matrizes (listas de listas);

Funções e modularização;

Estruturas de repetição e condicionais;

Manipulação de listas;

Números aleatórios com random.randint().
